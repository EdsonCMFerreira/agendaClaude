# agendaClaude

Agenda web em ASP.NET Core com CRUD de compromissos usando um arquivo JSON local.

## Campos

- Descrição
- Data
- Valor

## Executar

```powershell
dotnet run --urls http://localhost:5001
```

Acesse `http://localhost:5001` no navegador.

Os dados são persistidos em `data/agenda.json`.
